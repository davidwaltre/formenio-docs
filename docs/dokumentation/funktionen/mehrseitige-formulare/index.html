Mehrseitige Formulare

Lange Formulare lassen sich in mehrere Seiten aufteilen. Ausfüllende sehen immer nur eine Seite und klicken sich Schritt für Schritt durch – das wirkt aufgeräumter und erhöht die Abschlussquote.

Seiten anlegen

Im Formular-Editor sind die Felder nach Seite 1, Seite 2 … gruppiert.

  • Seite hinzufügen: Fügt am Ende eine weitere Seite hinzu.
  • Feld einer Seite zuordnen: In den Einstellungen eines Feldes über das Auswahlfeld Seite festlegen.
  • Reihenfolge ändern: Felder nach oben/unten schieben. Am Seitenanfang bzw. -ende wandert ein Feld automatisch auf die vorherige oder nächste Seite.

Eine Seite ohne Felder wird beim Speichern verworfen.

Für die Ausfüllenden

  • Navigation über Weiter / Zurück.
  • Ein optionaler Fortschrittsbalken zeigt, wie weit das Formular ausgefüllt ist. Ein-/ausschalten unter Einstellungen → Fortschritt anzeigen.
  • Pflichtfelder werden pro Seite geprüft, bevor es weitergeht.

Zusammenspiel mit anderen Funktionen

  • Bedingte Logik (Feld anzeigen / ausblenden / zur Pflicht machen) funktioniert seitenübergreifend – ein Feld auf Seite 3 kann von einer Antwort auf Seite 1 abhängen.
  • Berechnungen und Platzhalter greifen ebenfalls über alle Seiten hinweg.

Tipps

  • Frage pro Seite nur zusammengehörige Dinge ab (z. B. „Kontakt“, „Details“, „Upload“).
  • Die wichtigste bzw. einfachste Frage auf Seite 1 – ein begonnenes Formular wird eher abgeschlossen.
